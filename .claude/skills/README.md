# Agent skills

Project skills for coding agents working in this repo, so local and cloud sessions (Claude Code on the web) use the same versions.

| Skill | Use |
| --- | --- |
| `tdd` | Test-first red → green loop at agreed seams |
| `codebase-design` | Deep-module vocabulary `tdd` refers to |
| `code-review` | Two-axis review (standards, spec) of a diff since a fixed point |
| `pr` | PR body template |
